Em Java, o código delimitado por chaves ({ e }) é chamado de **bloco de código**. Um bloco agrupa instruções que são tratadas como uma unidade lógica, delimitando escopo e tempo de vida de variáveis e definindo onde determinadas regras da linguagem se aplicam.
### **Exemplo conceitual**

```
public class Example {

    public void execute() {
        int value = 10;
    }
}
```
### **Explicação linha a linha**

```
public class Example {
```

Abre um bloco de código que define o corpo da classe.

```
public void execute() {
```

Abre um bloco de código que define o corpo do método execute.

```
int value = 10;
```

Declara uma variável local dentro do bloco do método. Essa variável só existe dentro desse bloco.

```
}
```

Fecha o bloco do método. A partir desse ponto, a variável value deixa de existir.

```
}
```

Fecha o bloco da classe.

Blocos de código são usados em classes, métodos, construtores e estruturas de controle. Entender seus limites é essencial para compreender escopo e organização do código Java.
