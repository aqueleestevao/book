Uma declaração import pode conter apenas **um único** caractere curinga (*), e ele deve aparecer obrigatoriamente no final do nome do pacote. O Java não permite curingas em posições intermediárias nem múltiplos curingas na mesma importação.
### **Exemplo conceitual**

```
import java.util.*;
```
### **Explicação linha a linha**

```
import java.util.*;
```

Utiliza um único curinga ao final do pacote java.util, indicando que todas as classes diretamente nesse pacote podem ser referenciadas.
Declarações como import java.*.List; ou import java.util.*.*; não são válidas e resultam em erro de compilação. Essa restrição mantém o sistema de importações simples e previsível.
